# Révisions CM1

Petite application web (PWA) de révision pour le CM1 avec Kalou le calao : quiz, exercices par leçon, lecture à voix haute et réponses au micro (français).

Fonctionne sans compte ni connexion à Claude. Les progrès sont enregistrés sur le téléphone.

Installation : ouvrir l'adresse GitHub Pages dans Chrome sur le téléphone, puis menu ⋮ › « Ajouter à l'écran d'accueil ».
